# OpsAI SMS 데모

**[demo.html 열기](https://ds5tar.github.io/SMS/demo.html)**

옵스에이아이 SMS(서버 관리 시스템)의 관리 화면을 서버 없이 브라우저에서 둘러보는 데모입니다.
실제 SMS 서버에 서버 12대(웹·WAS·DB·파일·백업·AD·MSSQL·모니터링)의 14일 이력과 이벤트·로그·인벤토리·전산실 랙을
넣고 화면을 돌며 녹화한 응답으로 움직입니다. 열 때마다 시각이 지금으로 맞춰집니다.

| 화면 | 볼 것 |
|---|---|
| 종합 현황 | 등급별 이벤트 건수, 서버 상태 타일, 자원 상위 |
| 서버 · 서버 상세 | 요약, 성능 그래프(1시간~14일), 이벤트, 임계치, 로그, 인벤토리 |
| 이벤트 | 열린 이벤트와 해설, 요일·시간대별 통계 |
| 로그 | Linux journald·Windows 이벤트 로그 수집 결과 |
| 성능 · 장애 예측 | 여러 서버 비교, 디스크가 가득 찰 날 예측 |
| 3D 상면 | 전산실 랙과 서버 위치, 상태 색 |
| 설정 | 임계 규칙, 감시 대상, 통보, 알림 서버(문자·메일), 알림 발송 기록, 보관·용량, 등급 |

- 바꾸는 동작(저장·확인·삭제)은 데모라 저장되지 않습니다.
- AI 문의·AI 해설은 데모에 AI 가 붙어 있지 않아 규칙 기반 해설로 보입니다.
